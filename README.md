# Оно тебе надо

Проектная работа по вёрстке одностраничного сайта аукциона «Оно тебе надо» по макету из Figma.

## О проекте

На странице представлены:

- шапка сайта с навигацией и контактами;
- главный экран с заголовком и кнопкой;
- блок с карточками лотов;
- раздел «Об аукционе»;
- подвал с контактами, навигацией и ссылками на социальные сети.

## Технологии

- HTML5;
- CSS3;
- CSS Grid;
- Flexbox;
- семантическая вёрстка;
- БЭМ-подобное именование классов.

## Структура проекта

```text
ono-tebe-nado/
├── fonts/
├── images/
├── styles/
│   ├── global.css
│   └── style.css
├── index.html
└── README.md
```

## Запуск проекта

Для просмотра проекта откройте файл `index.html` в браузере.

## Макет

Проект выполнен по макету «Оно тебе надо» в Figma.
